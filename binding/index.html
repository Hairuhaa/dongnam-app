Scope

이런 작업을 합니다

대형 인쇄소가 맡기 어려워하는 50~300권 구간의 교재·보고서를 사무실 복합기와 스프링 제본기로 직접 처리합니다.

잘 맞는 작업

  • 학원 기말고사 워크북 — 같은 원고를 반별·학생 수만큼 찍어 제본
  • 수험서 분권 — 두꺼운 교재를 단원별로 나눠 스프링으로 묶기
  • 10권 이상 단체 작업 — 학교·학원·동아리·행사 자료
  • 50~300권 소량 교재·보고서 — 대형 인쇄소가 받기 애매한 수량

권수가 많을수록 작업 일정을 넉넉히 잡는 편이 좋습니다. 마감일이 있으면 문의할 때 먼저 알려주세요.

어려운 작업

  • 1~2권 낱권 — 스프링 값이 나오지 않아 단가를 맞추기 어렵습니다
  • 수천 부 옵셋 인쇄 카탈로그 — 사무용 복합기와 스프링 제본 장비의 범위 밖입니다
  • 무선(떡) 제본·양장 제본 — 스프링 제본만 합니다

애매한 수량이나 사양은 그냥 물어보셔도 됩니다. 가능한 방법이 있으면 솔직하게 안내드립니다.

한 권씩 똑같이, 넘김이 편하게

같은 원고를 여러 권 찍을 때 가장 중요한 건 권마다 인쇄 상태가 같은지입니다. 출력·제본을 한 곳에서 처리하기 때문에 페이지 순서와 스프링 위치가 어긋나는 일을 줄입니다. 서울 동대문구 사무실에서 직접 작업하고, 인근이면 직접 가져다 드립니다.

FAQ

자주 묻는 질문

페이지 수는 어떻게 세나요?
A4 양면 1장에 2페이지가 들어갑니다. 원고의 총 페이지 수를 기준으로 장수를 계산하니, PDF 기준 페이지 수를 그대로 알려주시면 됩니다. 홀수 페이지는 1장으로 올림 처리합니다. 표지를 따로 넣으실 경우 표지 페이지도 포함해서 알려주세요.
흑백과 컬러가 섞여 있으면 어떻게 계산하나요?
컬러 장수와 흑백 장수를 나눠 각각 계산합니다. 예를 들어 100장 중 컬러가 20장이면 컬러 20장 × 140원, 흑백 80장 × 80원으로 합산합니다. 계산기에서는 한 가지 종류로 단순 계산한 뒤, 카톡에서 실제 장수로 다시 정리해 드립니다.
파일은 어떤 형식으로 보내나요?
PDF가 가장 정확합니다. 한글·워드·엑셀 원본만 있으신 경우에도 카톡으로 보내주시면 출력 가능한 형태인지 확인해 드립니다. 페이지 순서와 여백이 중요하면 PDF로 변환해서 보내주세요.
표지나 코팅도 되나요?
기본 사양은 A4 일반 복사용지입니다. 별도 표지, 용지 종류 변경, 코팅처럼 사양이 달라지는 작업은 카톡으로 상담해 주세요. 원고에 표지 페이지를 포함해 보내주시면 그대로 출력해 제본합니다.
10권 미만도 가능한가요?
스프링 제본은 10권 이상 단체 작업을 기준으로 단가를 잡았습니다. 1~2권 낱권은 제본 단가가 맞지 않아 어렵습니다. 인쇄 수량이 적어도 되는 경우에는 카톡으로 상황을 알려주세요.
배송은 어떻게 되나요?
서울·수도권 인근 지역은 직접 배송 무료입니다. 그 외 지역은 택배로 보내드리며 운임은 협의합니다. 사무실(서울 동대문구 답십리로48길 55 1층)에서 직접 수령하셔도 됩니다. 영업시간은 매일 10:00–18:00입니다.
작업 기간은 얼마나 걸리나요?
분량과 권수에 따라 달라집니다. 마감일이 정해져 있다면 문의할 때 받아야 하는 날짜를 먼저 알려주세요. 일정이 맞는지 확인한 뒤 견적과 함께 안내드립니다.
계산기 금액 그대로 결제하면 되나요?
계산기는 위 단가 기준 예상 금액입니다. 실제 원고의 컬러 장수, 표지 포함 여부, 배송 방법에 따라 최종 금액이 정해집니다. 확정 금액과 결제 방법은 카톡 상담에서 안내드립니다.
